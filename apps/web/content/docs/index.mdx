Open Source Guru emails you when issues you could work on show up in the open-source repositories
you care about.

Follow a repository and pick labels such as <code>good{" "}first{" "}issue</code> or
<code>help{" "}wanted</code>. You get an email when:

- a new issue is opened with one of those labels, or
- one of those labels is added to an existing issue.

Each email says whether someone is already assigned to the issue, so you can tell at a glance if
it's still up for grabs.

## What's next

Open Source Guru is under active development. Coming soon:

- **Open Source Contributions**: your activity in open-source repositories, in one place.
- **Streaks and goals** to keep you going.
- **A public profile** and a README badge to show your contributions.
- **More channels**: Discord, Slack, webhooks and ntfy.
